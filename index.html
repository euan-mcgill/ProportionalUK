This site presents a long-term project to model real election results and the latest opinion polls using party list proportional representation. Many other valid (and potentially more effective) implementations of PR, but this site focuses on party list proportional using the D'Hondt method only - and compares the results with the current system: First past the post. One benefit of this method (especially "District" or "County" based constituencies) is that it retains three features which are preferred by the British public: (1) One person, one vote on a single ballot paper; (2) elected representatives which are connected to geographically-relevant constituencies; and (3) much less reliance on tactical voting.
